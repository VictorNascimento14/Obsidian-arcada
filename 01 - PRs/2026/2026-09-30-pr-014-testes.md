# PR #14 — chore(test): rodar Vitest com jsdom e Testing Library

## 🎯 Contexto

Módulo 0 do [[2026-09-30-plano-da-v1]]. Fecha a issue #2.

## 🔧 Mudanças

- `package.json` — `vitest`, `jsdom`, `@testing-library/react` e `@testing-library/dom`; script `test` = `vitest run`.
- `vite.config.ts` — bloco `test` com `environment: "jsdom"` e o arquivo de preparo.
- `src/test/setup.ts` — `afterEach(cleanup)`.
- `src/App.test.tsx` — teste de fumaça.

## 🧠 Decisões técnicas

- `vitest run`, não `vitest`: no CI o modo observação nunca termina.
- Sem `globals: true`: import explícito de `describe`/`it`/`expect` deixa claro de onde vem cada coisa — e por isso a limpeza do DOM é registrada à mão no preparo.

## ⚠️ Armadilhas e aprendizados

- Sem `globals`, a Testing Library não registra o `cleanup` sozinha: o DOM de um teste vazaria para o próximo.

## 🧪 Como testar

1. `npm test` → 1 teste passando.
2. `npm run lint && npm run type-check && npm run build` passam.
