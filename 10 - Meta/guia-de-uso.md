# Guia de uso do cofre

| Pasta | Para quê |
|---|---|
| `00 - Índice` | MOCs: ponto de partida de cada área |
| `01 - PRs` | Uma nota por PR, por ano |
| `02 - ADRs` | Decisões difíceis de reverter |
| `03 - Changelog` | Linha do tempo anual, duas leituras |
| `04 - Aprendizados` | Armadilhas e bugs instrutivos |
| `05 - Frontend` | `Componentes/<Area>/`, `Paginas/`, `Fluxos/` |
| `06 - Backend` | Reservada — não existe backend na v1 |
| `07 - Banco de Dados` | Reservada — não existe banco na v1 |
| `08 - Infra e Deploy` | `Runbooks/`, `Planos/`, `Pendencias/` |
| `09 - Templates` | Modelos de nota |
| `10 - Meta` | Documentação sobre o cofre |
